hermes-i386

i386 / 32-bit x86Debian (glibc)Alpine (musl)hermes-agent

Provisioning kit for running hermes-agent on i386 (32-bit x86) Linux. Developed and verified on a Lenovo ThinkPad X60s (Intel Core Duo L2500, 3.2 GB RAM) with Debian 12 bookworm i386 and Alpine Linux i386.

Why it exists

There is no 32-bit Node at the required version anywhere. hermes-agent needs Node ^22.22 / ^24 / ^26 with engine-strict, but no official i386 build exists — nodejs.org and the unofficial builds both 404 for linux-x86, and every Debian i386 Node is either too old or linked against a glibc newer than any released Debian. This kit ships a purpose-built, tested Node 22.22.0 for i386 instead.

What you end up with

  • ~/node22/ — Node 22.22.0, ia32, self-contained
  • /usr/local/bin/{node,npm,npx,corepack} — wired in, apt's left untouched
  • The mandatory V8 heap-clamp patch (ia32 can't reserve a multi-GB heap in a 4 GB address space)
  • A source-built libheif in 32-bit LIGHT mode for pillow-heif (no i686 wheels exist)
  • Auto-detecting scripts for Debian (glibc) vs Alpine (musl)

Quick start

git clone https://github.com/Va55/hermes-i386
cd hermes-i386
make all            # node + provision + verify

See the README for the full path, FINDINGS.md for the constraints hit, and BUILD-NOTES.md for the source-build details.
